# Classification Disputes - Practical Guide for HS Code Changes

## Overview

GST classification disputes arise when the correct HSN (Harmonized System of Nomenclature) code for a product is uncertain, leading to wrong rate application. This document covers practical guidance on switching HS codes, managing retrospective risk, and using the advance ruling process.

## Common Classification Disputes

### 1. Food Products (Chapter 16-22)

- Flavored milk vs. milk-based beverages (16% vs. 12%)
- Namkeen/snacks — whether "branded" or "unbranded" (affects exemption)
- Sweetened curd vs. yoghurt (different rates in different chapters)

### 2. Machinery and Parts (Chapter 84-85)

- Multi-function machines — classification by principal function
- Parts vs. accessories — different rates in many cases
- Solar inverters: Power conditioning equipment vs. solar equipment

### 3. Composite Supplies

- Works contract: Whether goods-dominant or service-dominant
- Software with hardware: Whether goods or services

## When to Change HS Code

### Proactive Correction

If you discover that the wrong HS code has been applied:

1. **Assess the impact**: Calculate the tax differential for past periods
2. **Prospective correction**: Change HS code from the current period onwards
3. **Past period liability**: If tax was underpaid, pay the differential with interest before a notice is issued (Section 73(5) — voluntary payment reduces penalty to nil)
4. **If tax was overpaid**: Apply for refund within 2 years under Section 54

### Retrospective Risk Assessment

| Scenario | Risk Level | Action |
|----------|-----------|--------|
| Lower HS code used (less tax paid) | High | Pay differential + interest immediately |
| Higher HS code used (more tax paid) | Low | Apply for refund; no penalty risk |
| HS code change is debatable | Medium | Get advance ruling first |
| Industry-wide practice supports your code | Low | Maintain documentation of trade practice |

## Advance Ruling Process

### When to File

- Before adopting a new HS code (especially for large-value products)
- When there is genuine ambiguity in classification
- When tax rate differential is significant (>5%)
- When the product is novel with no established trade practice

### How to File

1. **Form GST ARA-01**: Application for Advance Ruling
2. **Filing**: File with the state Advance Ruling Authority (AAR) of the state where the applicant is registered
3. **Fee**: Rs. 5,000 each under CGST and SGST (total Rs. 10,000)
4. **Documents needed**:
   - Product description and specifications
   - Manufacturing process (for manufactured goods)
   - Sample (if physical product)
   - Relevant customs tariff entries
   - Industry practice evidence
   - Any prior rulings on similar products

### Limitations of Advance Ruling

1. **Binding only on the applicant** and the jurisdictional officer — not on other taxpayers
2. **State-specific**: Each state's AAR may rule differently (has happened frequently)
3. **Appealable**: Both taxpayer and department can appeal to Appellate Authority for Advance Ruling (AAAR)
4. **Validity**: Until the law changes or the ruling is voided by AAAR/GSTAT
5. **Cannot be obtained for past transactions** — only for proposed transactions

## Practical Steps for Reclassification

### 1. Document Everything

Before changing HS codes:
- Internal memo explaining the reason for reclassification
- Technical product specifications
- Expert opinions (from customs brokers, industry consultants)
- Reference to similar products' classification in customs tariff
- General Explanatory Notes to HSN

### 2. Communication with Department

Consider proactive communication:
- Inform jurisdictional officer about the reclassification
- Seek informal guidance before formal change
- This demonstrates bona fide intent (reduces penalty risk)

### 3. Update All Systems

- Invoice templates (HSN code)
- E-way bill generation
- GSTR-1 reporting (HSN summary)
- Purchase records (for ITC verification)
- E-invoicing (mandatory HSN for turnover > Rs. 5 crore)

### 4. Monitor for Rate Change Notifications

After the GST Council's recommendation, rate changes/clarifications are notified via:
- Rate change notification (amendment to Schedule)
- Clarification circular (resolving classification disputes)
- These are published on cbic.gov.in and in official gazette

## Key Principles for Classification

1. **Rule 1**: Classification determined by the terms of the headings and section/chapter notes
2. **Rule 3(a)**: Specific description preferred over general description
3. **Rule 3(b)**: Composite goods classified by the component giving essential character
4. **Rule 3(c)**: When 3(a) and 3(b) don't apply, classify under the heading which occurs last in numerical order
5. **Trade parlance test**: How is the product known in the trade? Common commercial understanding often determines classification.
6. **Functional test**: What is the primary function of the product?
